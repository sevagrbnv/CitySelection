# CitySelection

Приложение для просмотра городов по тестовому заданию. Проект использует Kotlin
Multiplatform и общий интерфейс Compose для Android и iOS.

Сейчас реализован сетевой слой: получение городов с поиском и пагинацией,
преобразование DTO, обработка ошибок и внедрение зависимостей. Реализован экран
списка с Orbit, поиском, пагинацией, загрузкой и повтором после ошибок.
Реализованы переход к информации о городе, возврат к списку и внешний поиск
по имени города. Карта на MapLibre Native показывает города из API вокруг
видимой области и открывает модальную карточку выбранного города. Подложка —
OpenStreetMap через OpenFreeMap.

## Структура

Общий код находится в `shared/src/commonMain/kotlin/com/sevagrnbv/cityselection`:

```text
cities/
  data/
    remote/          API и DTO
    mapper/          преобразование DTO в модели
    repository/      реализации репозиториев
  domain/
    model/           City и CitiesPage
    repository/      контракты репозиториев
  presentation/
    list/            список, поиск и пагинация
    details/         экран информации о городе
    map/             карта, карточка и UI-состояние
    navigation/      контейнер фичи и маршруты
    common/          поля города, форматирование и названия стран
core/
  network/           клиент, обработка ошибок и результаты запросов
  designsystem/
    theme/           тема, цвета, типографика и размеры
    component/       общие UI-компоненты
    resource/        платформенная загрузка шрифтов (androidMain)
di/                  сборка графа зависимостей
```

Платформенные реализации в `androidMain` и `iosMain`, а также тесты в `commonTest`
повторяют пакеты соответствующего общего кода. Общие поля города находятся в
`presentation.common`: карта и детали используют их независимо друг от друга.

`App.kt` и платформенные точки входа остаются в корневом пакете приложения.
`androidApp` содержит Android Application, Activity и конфигурацию сборки;
`iosApp` — Swift-точку входа, интеграцию MapLibre и проект Xcode.
Новые Gradle-модули при группировке пакетов не создавались.

Документация: [сеть](docs/network-layer.md), [список](docs/cities-screen.md),
[детали](docs/city-details.md), [карта](docs/city-map.md), [дизайн-система](docs/design-system.md).

## Стек

Kotlin, Compose Multiplatform, Ktor, kotlinx.serialization, Coroutines, Koin.
Orbit управляет состоянием списка и карты городов, Navigation Compose — переходами
внутри фичи выбора города.
Версии зависимостей зафиксированы в `gradle/libs.versions.toml`.

## Принятые решения

### Карта: OpenStreetMap, OpenFreeMap и MapLibre Native

В интеграции карты у каждого компонента своя роль:

- **OpenStreetMap** — источник географических данных.
- **[OpenFreeMap](https://openfreemap.org/)** — сервис векторных тайлов и готового стиля Liberty.
- **[MapLibre Native](https://maplibre.org/projects/native/)** — движок, который отображает
  карту и обрабатывает жесты на Android и iOS.

MapLibre выбран за поддержку обеих мобильных платформ, настройку стиля и возможность
рисовать собственные метки городов. OpenFreeMap позволяет запустить задание без
API-ключей и собственного сервера тайлов. URL стиля находится в `CityMapConfig`.
Города, координаты и население загружаются из API задания; картографический сервис
предоставляет подложку.

На Android карта встроена через `AndroidView` и `MapView`, на iOS — через `UIKitView`
и Swift-адаптер `MLNMapView`. Платформенные адаптеры управляют SDK, его жизненным
циклом и событиями камеры. Запросы городов, состояние экрана, выбор города, кнопки
масштаба и карточка реализованы в общем Kotlin-коде. Такой подход сохраняет общий
сценарий работы и позволяет использовать нативные SDK на каждой платформе.

Метки передаются в SDK через GeoJSON и symbol-слои. Плашки с названием и хвостиком
рисуются в изображения; шрифт, цвета и геометрия заданы общим `CityPinStyle`.
Карточка города находится в Compose над нижним меню и использует те же поля,
что отдельный экран деталей.

### Границы кода и состояния

Пакеты `data`, `domain` и `presentation` разделяют сетевые DTO и реализации
репозиториев, модели и контракты, состояние и отображение экранов. Общие сетевые
компоненты и дизайн-система находятся в `core`. Для текущего объёма приложения
эти границы организованы пакетами внутри `shared`.

Orbit управляет списком, загрузкой городов на карте, ошибками и выбранным городом.
Состояние анимации карточки, Snackbar и ссылки на нативные SDK принадлежат UI.
Это позволяет держать ViewModel независимыми от `MapView` и `MLNMapView` и проверять
логику запросов общими тестами.

### Поиск, пагинация и ошибки

Поиск обновляет список при вводе с задержкой 300 мс, чтобы объединять быстрые
изменения текста. Новый запрос отменяет предыдущий; проверка поколения запроса
защищает список от поздних ответов. Пагинация начинается с первой страницы,
использует размер 20 по умолчанию и подгружает следующую страницу при приближении
к концу списка. Ошибка следующей страницы сохраняет уже загруженные города.

На карте запрос отправляется после изменения видимой области с короткой задержкой.
Радиус охватывает её углы и вычисляется общим алгоритмом, поэтому Android и iOS
используют одинаковые параметры выборки. Подробности — в [документации карты](docs/city-map.md).

Ожидаемые сетевые ошибки преобразуются в `NetworkResult` и `NetworkError`.
Отмена корутины пробрасывается дальше, неизвестные исключения не маскируются
под сетевую ошибку. Ошибки загрузки карты и API обрабатываются отдельно:
повтор запроса городов сохраняет подложку и положение камеры.

### Дизайн-система

Цвета, Roboto, типографика, отступы и общие компоненты вынесены в дизайн-систему.
Ширина элементов зависит от доступного пространства, высота поля поиска и кнопок
задана как минимальная. Это сохраняет размеры из макета при обычном масштабе текста
и позволяет компонентам расти при увеличенном системном шрифте.

## Сборка и проверки

Для Android необходим установленный SDK; путь к нему задаётся локально в
`local.properties` или через настройки окружения. Параметры JVM находятся в
`gradle/gradle-daemon-jvm.properties`.

Тесты общего сетевого слоя на JVM:

```sh
./gradlew :shared:testAndroidHostTest
```

Release-сборка Android:

```sh
./gradlew :androidApp:assembleRelease
```

APK: `androidApp/build/outputs/apk/release/androidApp-release-unsigned.apk`.
Подпись release и минификация пока не настроены.

Компиляция общего кода для iOS Simulator на Mac с Xcode:

```sh
./gradlew :shared:compileKotlinIosSimulatorArm64
```

Для запуска iOS откройте `iosApp/iosApp.xcodeproj` в Xcode и настройте подпись.
