# Сетевой слой

Модуль `shared` содержит API городов, преобразование DTO в модели приложения и
репозиторий. Android использует движок Ktor OkHttp, iOS — Darwin.
Интерфейс приложения обращается к `CitiesRepository`.

## Контракт API

Базовый адрес: `http://dev-dep.tools.urent.tech:8080`.

Параметры `GET /api/cities`:

- `query` — фильтр по названию; пробелы по краям удаляются, кодирование выполняет Ktor.
- `page` — номер страницы, начиная с 1.
- `limit` — положительный размер страницы; по умолчанию в приложении 20.

Ответ содержит `items`, `page`, `limit`, `total`.
Поля города: `id`, `name`, `country`, `lat`, `lon`, `pop`.
Название и код страны сохраняются как на сервере. Отсутствующие или явно пустые
координаты и население представлены значением `null`. Форматирование населения
и перевод кодов стран в отображаемые названия относятся к презентации.

Идентификатор, название, страна и поля оболочки страницы обязательны.
Отсутствующие обязательные поля и несовместимые JSON-типы приводят к
`InvalidResponse`. Мапперы преобразуют декодированные значения без дополнительной
валидации данных города или параметров пагинации.

Признак следующей страницы вычисляется по возвращённым `page`, `limit` и `total`.
Пустая страница завершает пагинацию, чтобы изменение набора данных не приводило
к бесконечным запросам. Умножение выполняется в `Long`, чтобы избежать переполнения
`Int`. Репозиторий не хранит состояние: задержка поиска, отмена предыдущего запроса,
накопление страниц и защита от устаревших результатов реализованы в презентации.
Подробнее: [Список городов](cities-screen.md).

При проверке 7 октября 2026 года поиск `Moscow` возвращал города, а `Москва` —
пустой список. Страны приходят кодами вроде `RU`, а не названиями из макета.
Полная спецификация nullable-полей и серверных правил валидации не подтверждена.
Маршрут `GET /api/cities/map` подключён отдельным `CityMapRepository`; контракт и
расчёт области описаны в [city-map.md](city-map.md).

## Результат и ошибки

Общие `NetworkResult<T>` и `NetworkError` находятся в `core/network`.
`CitiesRepository` возвращает `NetworkResult<CitiesPage>`.

- `Success` содержит модель ответа.
- `Failure` содержит тип ошибки и исходное исключение для диагностики.

Типы ошибок:

- `Network` — ошибка транспорта; сама по себе не доказывает отсутствие интернета.
- `Timeout` — таймаут запроса, соединения или чтения из сокета.
- `Http(statusCode)` — неуспешный HTTP-ответ, включая ограничение частоты запросов.
- `InvalidResponse` — повреждённый JSON, отсутствие обязательных полей,
  несовместимые типы полей или тип содержимого ответа.

UI должен отображать сообщение по типу ошибки; текст исходного исключения
предназначен для диагностики. Отмена корутины и неожиданные программные ошибки
пробрасываются наверх. Репозитории передают параметры запроса без дополнительных
проверок; допустимые значения формируют вызывающие их ViewModel и адаптеры карты.

Автоматические повторы на уровне приложения не настроены. Явный повтор инициирует UI.
Логирование запросов не подключено. Таймаут соединения — 10 секунд, чтения из
сокета — 15 секунд, всего запроса — 20 секунд. Перенаправления отключены.

В задании указан HTTP-адрес. Android Network Security Config и iOS ATS разрешают
незашифрованное соединение только с этим доменом, без поддоменов. Проверка
TLS-сертификатов не отключается. Для HTTPS-адреса нужно согласованно обновить
базовый URL и платформенные настройки.

## Внедрение зависимостей и ресурсы

`createAppKoin()` создаёт изолированный граф без регистрации глобального контекста
Koin. Android создаёт его в `CitySelectionApplication`, iOS — один раз при первом
обращении из `MainViewController`. Зависимости передаются через конструкторы.

На один граф создаётся один HTTP-клиент. Клиент владеет движком, созданным через
фабрику, и освобождает его при закрытии. Закрытие графа закрывает клиент.
Движок, переданный напрямую в тестах, закрывает вызывающая сторона.

Тесты создают репозиторий с MockEngine и не обращаются к реальному серверу.

## Проверки

```sh
./gradlew :shared:testAndroidHostTest :androidApp:assembleRelease
./gradlew :shared:compileKotlinIosSimulatorArm64
```

Тесты проверяют кодирование параметров, nullable-данные, границы пагинации,
HTTP-ошибки, сбои транспорта, ошибки десериализации, отмену, аргументы запроса
и освобождение движка клиента.

APK: `androidApp/build/outputs/apk/release/androidApp-release-unsigned.apk`.
Подпись release и минификация пока не настроены. Сборка Android и компиляция общего
кода для iOS не подтверждают поведение на устройстве. Проверки R8 и работы на
устройстве относятся к этапу подготовки готового приложения к сдаче.
