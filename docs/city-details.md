# Информация о городе

`CitySelectionRoute` содержит типизированный `NavHost`: список городов, карту и детали.
Нижняя панель принадлежит контейнеру фичи и отображается на списке и карте,
кроме первоначальной ошибки списка.
Кнопка «Назад» возвращает предыдущую запись стека; системный возврат обрабатывает
Navigation Compose. ViewModel списка принадлежит его записи навигации, поэтому
при переходе к деталям сохраняются загруженные страницы и поисковый запрос.
Позиция прокрутки и текст поля сохраняются средствами Compose и навигации.

## Данные

В задании нет запроса получения города по идентификатору. Поэтому типизированный
маршрут `CityDetailsDestination` содержит id и небольшой снимок выбранного города:
название, отображаемую страну и nullable-население. Аргументы сохраняются в стеке
навигации и не требуют временного глобального хранилища для восстановления деталей.
Данные соответствуют моменту загрузки списка; отдельного обновления деталей нет.

Население группируется неразрывными пробелами, единица измерения берётся из ресурсов.
`null` отображается как «Нет данных», ноль сохраняется как `0 чел`. Отдельная ViewModel
для неизменяемого снимка не нужна. Экран принимает данные и обработчики действий,
поэтому превью не зависит от DI и навигационного контроллера. Содержимое прокручивается,
а кнопка поиска закреплена снизу.

## Внешний поиск

Кнопка открывает `https://www.google.com/search` с параметром `q`, содержащим имя
выбранного города. URL формируется через `URLBuilder`: кириллица, пробелы и специальные
символы передаются как один параметр. Открытие выполняет платформенный `LocalUriHandler`.
Если обработчик сообщает, что URL открыть нельзя, показывается сообщение в Snackbar.
После открытия браузера управление внешним приложением остаётся у пользователя.

## Проверки

Автоматические тесты проверяют перенос населения из модели API в презентацию,
группировку числа без переполнения, сохранение нуля и кодирование сложного имени
в поисковом URL.

Проверено 7 октября 2026 года: все 25 тестов прошли, Android release собран,
общий код для iOS Simulator ARM64 скомпилирован. На Android-эмуляторе проверена
копия release APK с тестовой подписью: данные города и население, отсутствие
нижней панели на деталях, возврат кнопкой и системным Back, сохранение запроса
`Moscow` и позиции прокрутки списка. Поисковая кнопка запустила Chrome; браузер
показал экран первоначальной настройки, поэтому загрузка результатов поиска
не подтверждена. Восстановление после уничтожения процесса и запуск iOS-приложения
не проверялись.

```sh
./gradlew :shared:testAndroidHostTest :androidApp:assembleRelease
./gradlew :shared:compileKotlinIosSimulatorArm64
```
