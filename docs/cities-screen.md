# Список городов

Экран реализован в общем модуле `shared` и используется Android- и iOS-приложениями.
Точная подгонка размеров, шрифтов и отступов под Figma остаётся отдельным этапом.
Переход к информации о городе и дополнительная карта пока не подключены.

## Состояние и границы ответственности

`CitiesViewModel` использует Orbit и получает `CitiesRepository` и `CountryNames`
через конструктор. ViewModel создаётся Koin и принадлежит платформенному
`ViewModelStore`. Корутинные запросы отменяются при уничтожении ViewModel.

Нижняя панель `CitySelectionBottomBar` принадлежит контейнеру фичи выбора города
`CitySelectionRoute`. `App` подключает фичу, а контейнер передаёт экрану списка
отступы через `Modifier` и помечает их потреблёнными, чтобы вложенный `Scaffold`
не применял системные отступы повторно. Экран списка отвечает за свой заголовок
и содержимое. Пункт карты пока неактивен; переключение представлений будет
ответственностью контейнера фичи после подключения карты.

`CitiesRoute` получает ViewModel и подписывается на Orbit с учётом жизненного цикла.
`CitiesScreen` принимает только состояние и обработчики событий; превью не требует
сети или DI. Все тексты интерфейса находятся в Compose Resources, цвета — в теме.
Коды стран преобразуются в отображаемые названия во ViewModel средствами платформы.
Неизвестные коды сохраняются.

Состояния основного содержимого:

- `Loading` — первоначальная загрузка или смена поискового запроса; отображается skeleton.
- `Data` — список городов и признак наличия следующей страницы.
- `Empty` — успешный ответ без городов; предлагается изменить запрос.
- `Error` — ошибка первой страницы с кнопкой повторного запроса.

Следующая страница имеет собственные состояния `Idle`, `Loading` и `Error`.
Ошибки отображаются по `NetworkError`; сообщения исключений не выводятся пользователю.

## Поиск

Поле использует `TextFieldState`: ввод и позиция курсора обновляются синхронно,
а текст наблюдается через `snapshotFlow`. Это исключает задержку ввода из-за
асинхронных Orbit-событий. Для запроса удаляются пробелы по краям; повтор того же
нормализованного текста не вызывает загрузку.

Смена запроса сразу отменяет предыдущую загрузку, очищает пагинацию и переводит
содержимое в `Loading`. Сетевой запрос выполняется через 300 мс после последнего
изменения. Первая загрузка и явный повтор после ошибки выполняются без этой задержки.

Каждый новый поиск получает номер поколения. Ответ применяется только к тому
поколению, для которого был запрошен. Это защищает от старых результатов даже
в случае источника данных, который не соблюдает отмену корутин.

## Пагинация

Первая страница запрашивается с размером 30. Последующие запросы используют
возвращённый сервером размер страницы. Загрузка начинается при приближении
к последним пяти элементам списка.

Решения о запуске запросов и применение результатов сериализованы через `Mutex`.
Сеть и задержка поиска выполняются вне блокировки. Состояние `Loading` следующей
страницы исключает параллельные запросы одной страницы.

Успешная страница добавляется к имеющимся городам. Повторные идентификаторы
удаляются, ключи элементов списка стабильны. При ошибке список сохраняется,
автоматические запросы останавливаются, явный повтор запрашивает ту же страницу.
После окончания списка или пустой страницы новые запросы не отправляются.

## Проверки

```sh
./gradlew :shared:testAndroidHostTest :androidApp:assembleRelease
./gradlew :shared:compileKotlinIosSimulatorArm64
```

Тесты ViewModel используют Orbit Test, поддельный репозиторий и виртуальное время.
Проверяются загрузка, преобразование страны, задержка поиска, немедленная отмена,
старые ответы, однократная загрузка страницы, дубликаты, повтор после ошибок,
сброс пагинации при поиске и завершение по пустой странице.

Проверено 7 октября 2026 года: 9 тестов ViewModel и 14 тестов сетевого слоя
и ресурсов клиента прошли; Android release собран, общий код для iOS Simulator
ARM64 скомпилирован.

На Android-эмуляторе проверена копия release APK с тестовой подписью:
переход skeleton → список, поиск `Moscow`, пустой результат, очистка поля
и загрузка второй страницы при прокрутке. Города второй страницы сверены с API.
Ошибки и гонки запросов проверены автоматическими тестами; отключение сети
на эмуляторе не проверялось. iOS-компиляция подтверждает совместимость общего
кода, но не запуск iOS-приложения.
